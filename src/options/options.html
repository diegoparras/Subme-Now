3. Transcripción y panel

Color de la interfaz
Cambia el color de acento de toda la interfaz (íconos, pestañas, botones y resaltados) en el panel de YouTube, en esta página y en la ventana de desbloqueo. "Automático" usa el violeta de Subme Now.

4. Acciones personalizadas

Crea tus propios botones de IA. El prompt recibe automáticamente la transcripción y los datos del video.

5. Seguridad: proteger las API keys

Privacidad

  • Subme Now no tiene servidores propios: la transcripción se obtiene directamente de YouTube y las consultas van directo del navegador al proveedor que elijas.
  • Las API keys se guardan en chrome.storage.local (no se sincronizan con tu cuenta).
  • Nunca se envía nada a la IA sin que hagas clic en una acción (salvo que actives el resumen automático).
